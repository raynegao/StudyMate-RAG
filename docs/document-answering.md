# 指定 PDF 问答与整篇概括

更新日期：2026-09-05。本次修复的是“上传后询问核心概念却只返回检索提示”的实际使用问题，不改变上一轮历史评测的统计口径。

## 使用方式

```bash
scripts/run_real_course.sh
```

打开 `http://127.0.0.1:8502`，通过“添加资料”上传 PDF，上传后默认选中；也可以在“我的资料 → 正在阅读”切换文件。2026-09-06 的消费端界面改版见 [界面说明](consumer-ui.md)，下方历史模型验收仍保留原口径。

- 选择“问资料”，输入“这份资料的核心概念是什么？”，会自动走整篇概括。自动识别只针对整份资料的概览问法；“总结第三章的公式”这类带具体对象的问题仍按原文检索（2026-10-14 收窄）。
- 选择“概括全文”，不填要求也可以直接点击“生成概括”。
- 提具体问题时，只检索选中的 PDF，不把其他课程文档的片段混进来。
- 切换文档后不展示上一份 PDF 的旧答案；请求失败也不会把上次成功答案误当本次结果。

## 生成与隐私

用户已明确要求使用 DeepSeek，因此常规入口从 `.env.local` 加载凭据并启用生成；不打印密钥，前端进程不继承该 Key。点击回答会发送所选 PDF 的必要原文，整篇概括会处理全部已索引文字。不会自动发送其他 PDF，不迁移、删除或重建旧私人索引。

不希望外发时运行 `scripts/run_real_course.sh local`，或设置 `STUDYMATE_COURSE_MODE=retrieval_only`。`prepare` 和 `verify` 始终强制纯本地；本地模式明确不提供生成式概括。自动化外部模型验收仍只用公开虚构 PDF，实际私人问答内容不写入公开产物。

## 整篇概括的范围

概括直接读取指定文档全部已索引片段，按页和片段编号排序，不走 embedding 相似度、top-k 或拒答分数门槛。每批原文最多 12000 字符、最多 8 批；超过一批时先归纳各部分，再综合各部分摘要，保留原始引用编号。所有批次预算在外部调用前检查，超限返回明确错误，不只截取开头。

API 响应保留覆盖的有文本页数和片段数；阅读页面只显示已阅读的文字页数，并把引用编号转换为中文页码链接、按页折叠原文。覆盖是“全部已索引文字”，不包含扫描图片、未提取文字，也不保证模型在短摘要中复述每个细节。引用校验仅确保来源编号有效，不代替语义和专业判断；校验失败返回 `502 summary_citations_invalid` 并丢弃该次输出，页面提示可直接重试；涉及合同等文档时只归纳原文。

单次 LLM 默认阶段超时 30 秒、连接最多 5 秒、零自动重试。整篇概括最多 8 次分段请求与 1 次综合请求；分段请求默认 4 路并发（2026-10-16 起，`STUDYMATE_SUMMARY_CONCURRENCY` 可设 1 到 8），摘要按页序进入综合，任何一段失败即停止发送尚未开始的分段。前端预算默认 150 秒，并发数为 1 时为 330 秒。短文档通常只调用一次；预算不是任意网络条件下的硬 SLA。

真实文档测试发现 V4 默认思考消耗完旧的 1536 token 输出额度，导致接口 HTTP 200 但正文为空。现依据 [DeepSeek 官方说明](https://api-docs.deepseek.com/guides/thinking_mode/) 在整篇概括中显式传 `thinking.type=disabled`；具体问答保留 `enabled`，避免统一关闭后的回归。两条路径输出额度均为 4096；`finish_reason=length` 返回 `llm_output_incomplete`，不把截断回答当成功，也不读取或展示模型思考正文。

## 验证

- `scripts/test.sh`：98 项通过，后端覆盖率 87.25%。
- 新增真实 Chroma 文档筛选/页序测试，验证另一个 PDF 不会混入。
- 20 片段尾部覆盖测试；3 批归纳再综合测试；超预算在调用前失败测试。
- 无效引用、缺失文档、缺少文档选择、非法 ID、纯本地不调用模型测试。
- DeepSeek 非思考请求参数、回答额度、空/非空截断输出均不能伪装成功的回归测试。
- Streamlit AppTest 验证默认选择、概括请求参数、覆盖提示、切换文档隐藏旧答案。
- 隔离 Docker E2E 使用公开 PDF，验证原问题“这份资料的核心概念是什么？”返回真实 DeepSeek 概括、完整片段覆盖及有效引用，并继续检查重启持久化和隔离清理。
- 用户明确授权的实际 PDF 已在本机 Chrome 返回概括，覆盖全部 3 个文本页、39 个片段，引用仅来自所选文件；不保存其私人正文或回答到公开产物。
- 最终代码的公开 30 题回归：30/30 通过关键词与引用页检查。12/12 无答案题正确拒答；6 道可回答变体均找到证据并返回回答，5/6 通过自动关键词检查。这仍是小规模开发回归，不是普遍准确性保证。
