# Hard-question evaluation

Generated by `scripts/evaluate_hard.py`. The original benchmarks saturate (every retriever finds almost every gold page), so they cannot show whether a change helps or hurts. This set adds harder question types and re-measures the original questions with the same rule as a reference. Questions were fixed before the first run and are not tuned to results.

Measured at `2026-10-16T02:21:07.442396+00:00` with `BAAI/bge-small-zh-v1.5`, chunk size 300, overlap 60, 384-token chunk budget.

## Method

- **Document scope** ranks only the chunks of the gold PDF, which is how the app retrieves for a selected document. **Global scope** ranks every chunk in the corpus and is shown for comparison.
- A question counts as retrieved at K only when every evidence group has a chunk from one of its pages in the top K. Multi-page questions therefore need all of their pages.
- Public hard PDFs keep the original pages 2-4 unchanged and add page 5 with confusable entities that differ only in name and value, plus procedures that point back to earlier pages.
- Question types: **paraphrase** avoids the source's named entities; **distractor** has a confusable entity in the same document; **boundary** and **condition** ask about an edge value or rule; **numeric** asks for a specific number; **multi_page** needs several pages.

## Reproduce

```bash
.venv/bin/python scripts/generate_evaluation_assets.py
.venv/bin/python scripts/evaluate_hard.py            # public + local real-course retrieval
set -a && source .env.local && set +a
.venv/bin/python scripts/evaluate_hard.py --with-llm # also DeepSeek answers on the public hard set
.venv/bin/python scripts/evaluate_hard.py --public-only
```

Machine-readable results: [hard-results.json](../output/evaluation/hard-results.json).

## Limits

- The sets are small (24 public and 15 real-course questions), so one question moves a rate by 4 to 7 points.
- Keyword and forbidden-value checks are auditable proxies, not a semantic grader; a correct answer that also mentions the distractor value for contrast is counted as wrong.
- The public hard pages were written to be confusable on purpose; they measure robustness, not typical document difficulty.
