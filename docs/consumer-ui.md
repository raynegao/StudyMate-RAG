# StudyMate 阅读界面改版

更新日期：2026-09-06。

## 设计参考

本次查阅 GitHub 公开项目，只借鉴信息布局和交互思路，未复制第三方代码、图片、字体或品牌资产：

- [Streamlit LLM Examples](https://github.com/streamlit/llm-examples)：简化文件问答入口，让用户围绕资料与问题操作。
- [Kotaemon](https://github.com/Cinnamon/kotaemon)：简洁的文档问答界面，分开管理资料、阅读回答与核对出处；实际查看其 README 界面预览。
- [RAGFlow](https://github.com/infiniflow/ragflow)：可追溯的引用和原文快速查看。

## 本次调整

- 采用暖白底、深绿重点色、衬线主标题和系统中文字体，不加载外部字体或脚本。
- 侧栏管理资料，中间专注阅读；增加三个快捷阅读方向，点击只预填，不自动发送内容。
- “问资料 / 概括全文”取代开发式参数表单。沿用后端默认检索数量，不在消费端展示数字滑块。
- 内部来源编号转为可点击的“第几页”。同页多个引用合并展示，但保留每段原文；未实际引用的候选不展示。本地原文查找仍展示相关内容。
- 隐藏内部 ID、向量距离、片段计数、部署入口与调试工具条。API 协议及机器字段保持不变。
- 上传、等待、空库、离线、拒答、超时、删除确认均使用读者能理解的文案。未知错误不透传 HTTP 正文或服务消息。
- 保留外发说明（按所选提供方显示 DeepSeek 或 Gemini）、扫描件限制和 AI 核对提醒，不作“所有内容完全本地”的误导承诺。
- 2026-10-17 起地址栏的 `doc` 参数记住所选资料，刷新后不再回落到最新上传的文件；该参数只含内部 ID，页面文案仍不展示 ID。
- 删除需二次确认，失败时保留确认状态；新上传自动选中并清空上传选择，避免误点重复添加。

- 浏览器交互使用虚构预览数据，不读取私人正文，也不向 DeepSeek 发送私人资料。

复现隔离预览：

```bash
PYTHONPATH=. .venv/bin/python -m streamlit run scripts/ui_preview.py --server.port 8513
```

默认预览可点击生成固定的虚构回答；`?scenario=empty`、`?scenario=local`、`?scenario=error` 分别展示空库、本地原文、离线状态。此入口不连接任何模型或资料库，不保存或删除文件，不能当作真实模型回答验收。

正式入口仍为 `scripts/run_real_course.sh`，打开 `http://127.0.0.1:8502/`。本轮没有修改底层分块、检索或生成算法，不重复计算历史语料评测。

## 维护注意

样式使用 Streamlit 的 `data-testid` 和原生布局，不依赖随机 CSS 类名，但组件升级后仍需重新检查桌面与窄屏。引用页码是回答依据所在的原文摘录，不是内嵌 PDF 阅读器，也不代表已核验每个断言。

本轮更新使用说明；旧演示视频和截图保留原始版本，不能作为改版后的 UI 截图。

Chrome 若把本来就是中文的页面再次自动翻译，可能改写“概括全文”等文字。视觉核对时通过翻译弹窗切回原文，不修改全局翻译设置。
