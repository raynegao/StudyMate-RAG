## 标注修订和自动评分边界

`REAL-B-02` 的原始标准页为 14，原文复核发现第 15 页也直接给出了所问熵定义，因此增加可接受页 15，同时保留原始页指标。Recall@1 从原始页口径 10/15 到可接受页口径 11/15，不能算作检索算法提升。top-6 在两个口径下均为 15/15。

`OBS-10` 只问频段，最小回答关键词修订为 `8.4 GHz`，原始含“状态摘要”的全关键词检查仍单独保存。此项是评分修订，不是生成能力提升。

最新复跑未通过自动检查的两题保留原分数，没有通过反复重跑挑选全对结果：

- `OBS-01` 回答“紫晶校准牌。[S1]”，回答了“用什么标记”，但未重复评分表里的“零点校准”。
- `ANS-05` 回答第十三个作业在等待队列等待已有作业释放槽位，但未重复评分表里的并发容量数字。

人工核对认为两者表达了所问事实；这只是本次审阅意见，未替代或回填自动分数。相反，关键词命中与引用页正确也不能证明每个断言均获原文支持。小规模合成题和开发阶段保留集不是盲测，12/12 拒答不能保证未来所有问题都可靠拒答。

## 使用与隐私边界

```bash
scripts/run_real_course.sh
# 浏览器打开 http://127.0.0.1:8502

scripts/run_real_course.sh verify
.venv/bin/python scripts/verify_token_budget.py
```

课程 profile 强制本地检索，使用新建的 `real-course-v2` 存储。原始授权 PDF 仅在本地读取和复制；原 PDF 路径、导入回执、上传文件和向量均被 Git 忽略。现有旧私人索引没有读取、迁移、重建或对外发送。外部 LLM 验收只使用公开虚构 PDF。

升级分块参数不会自动更新旧索引。普通默认 profile 仍是生成模式；不要将私人课程资料上传到该实例。课程实例不提供外部模型生成答案，这是隐私边界而不是未修复故障。
